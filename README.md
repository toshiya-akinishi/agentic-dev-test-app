# agentic-dev-test-app

**J-Tour Fan App** のフロントエンド（モバイルアプリ）。

## 技術スタック

- TypeScript (strict)
- React Native / Expo（expo-router によるファイルベースルーティング）
- TanStack Query v5（サーバ状態・ポーリング・オフライン永続化）
- Jotai（クライアント状態）
